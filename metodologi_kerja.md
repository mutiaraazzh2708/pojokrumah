# Metodologi Kerja

## 1. Pendahuluan
Pendekatan Agile dipilih karena lebih fleksibel, cepat, dan responsif terhadap perubahan. Agile memprioritaskan kolaborasi, hasil bernilai, dan iterasi cepat, sehingga meminimalkan risiko dan memastikan kebutuhan terpenuhi secara efektif.

## 2. Tahapan Pengembangan (Agile)

Dalam penerapan Agile, pengembangan dilakukan secara bertahap dan berulang (iteratif). Berikut adalah tahapan yang dilakukan:

### A. Perencanaan (Sprint Planning)
Pada tahap awal setiap iterasi, dilakukan perencanaan mengenai fitur apa saja yang akan dikerjakan.
- **Backlog**: Menyusun daftar fitur atau tugas yang perlu diselesaikan (Product Backlog).
- **Prioritas**: Menentukan fitur mana yang paling penting untuk dikerjakan terlebih dahulu pada sprint ini.

### B. Desain & Implementasi (Development)
Tahap pengerjaan fitur sesuai dengan desain yang disepakati.
- **Desain UI/UX**: Merancang antarmuka yang user-friendly dengan HTML dan CSS.
- **Coding**: Mengimplementasikan logika fitur menggunakan PHP dan MySQL.
- **Database**: Mengelola struktur data yang dibutuhkan untuk fitur yang sedang dikerjakan.

### C. Pengujian (Testing)
Setiap fitur yang selesai dikerjakan langsung diuji untuk memastikan tidak ada error sebelum lanjut ke fitur berikutnya.
- **Unit Testing**: Menguji fungsi-fungsi kecil secara individu.
- **Integration Testing**: Memastikan fitur baru berjalan baik dengan sistem yang sudah ada.

### D. Tinjauan & Evaluasi (Review & Retrospective)
Setelah satu siklus sprint selesai, hasil kerja didemonstrasikan dan dievaluasi.
- **Review**: Melihat apakah fitur sudah sesuai dengan kebutuhan pengguna.
- **Evaluasi**: Mencari tahu apa yang bisa diperbaiki untuk sprint berikutnya agar proses pengembangan lebih efisien.

## 3. Alat dan Perangkat Lunak (Tools)

Dalam proses pengembangan, digunakan berbagai perangkat lunak pendukung, antara lain:

| Kategori | Nama Tools | Kegunaan |
| :--- | :--- | :--- |
| **Sistem Operasi** | Windows 10/11 | Lingkungan kerja utama. |
| **Text Editor / IDE** | Visual Studio Code | Menulis dan mengedit kode program (PHP, HTML, CSS, JS). |
| **Web Server** | XAMPP (Apache) | Menjalankan server lokal. |
| **Database Server** | MySQL (via XAMPP) | Manajemen basis data. |
| **Database Management** | phpMyAdmin | Antarmuka grafis untuk mengelola database MySQL. |
| **Web Browser** | Google Chrome / Edge | Menjalankan dan menguji aplikasi web. |
